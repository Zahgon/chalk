# Migration tooling

`testdata/golden.json` is the acceptance oracle for this port. It is generated by
executing the **original JavaScript chalk**, so the expectations in `golden_test.go`
can never drift toward the Go implementation.

The generator is a Node script and is deliberately **not** part of this Go module —
shipping JavaScript inside the port would defeat the purpose of the migration. It is
archived alongside the other migration artifacts:

    deliverables/chalk_chalk/migration-tooling/gen-golden.mjs

## Regenerating the golden corpus

```sh
node <path-to-migration-tooling>/gen-golden.mjs <path-to-original-chalk-repo> testdata/golden.json
```

The script imports `source/index.js` and `source/vendor/ansi-styles/index.js` from an
untouched upstream chalk checkout and emits, for every ANSI style and for levels 0–3,
the exact strings the original produces.

`differential.sh` compares this port against the original at runtime.
